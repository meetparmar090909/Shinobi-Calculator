# Naruto Sage Mode Calculator

A visually stunning, Naruto-themed web calculator featuring Sage Mode aesthetics, glowing displays, and shinobi-style button controls.

## Features

- **Naruto Theme**: Inspired by the Naruto series with Sage Mode and Hidden Leaf aesthetics.
- **Dynamic Display**: Glowing current operand and previous calculation display.
- **Interactive UI**: Custom buttons with hover and active effects (Rasengan style).
- **Responsive Design**: Works seamlessly on desktop and mobile devices.
- **Chakra Particles**: Animated floating particles for an immersive experience.

## Files

- `index.html`: The main structure of the calculator.
- `style.css`: Custom styling for the Naruto theme.
- `script.js`: Logic for calculations and UI updates.

## How to Use

Simply open `index.html` in any modern web browser to start using the calculator.

- Use the numbers and operators to perform calculations.
- **AC**: Clear all operands and results.
- **DEL**: Delete the last entered character.
- **BELIEVE IT!**: Calculate the result of the current expression.

## Technologies Used

- HTML5
- CSS3 (Custom Variables, Flexbox, Grid, Animations)
- JavaScript (ES6+)
